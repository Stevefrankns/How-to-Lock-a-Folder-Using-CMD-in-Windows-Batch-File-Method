How to Lock a Folder Using CMD in Windows (Batch File Method)

Looking for a quick, native way to restrict access to your sensitive files without downloading third-party software? Using a simple batch script in the Command Prompt (CMD) allows you to hide and lock a folder with a password.

Quick Answer

To lock a folder using CMD, you create a batch file (.bat) using Notepad. This script prompts the user for a password, and if correct, it reveals a hidden system folder. When locked, it uses the attrib +h +s command to hide the folder from standard Windows Explorer views. Note: This method deters casual snooping but is not true encryption.

The Basics

Why Lock a Folder Using CMD?

When you share a PC at home or in a small office, you don't always need military-grade encryption just to keep tax documents or personal photos out of sight. The CMD folder lock method uses built-in Windows tools to create a password-protected gateway.

It is entirely free, requires no admin installations, and executes instantly. However, understanding exactly how it hides your files is critical so you don't accidentally lose data.

What is a batch file?

A batch file (ending in .bat) is simply a text file containing a series of commands that the Windows Command Prompt executes sequentially. Instead of typing commands one by one to hide a folder, the script automates the process and adds a password prompt.

Preparation

What You Need Before Starting

  • A Windows PC (Works on Windows 7, 10, and Windows 11).
  • Notepad (built into Windows).
  • A folder containing the files you want to lock.

Step-by-Step

Batch File Folder Lock — Complete Code

Follow these exact steps to create your folder lock notepad code.

Step 1: Create the batch file

  1. Open Notepad on your Windows computer.
  2. Copy and paste the exact code from the block below.
locker.bat 
cls
@ECHO OFF
title Folder Locker
if EXIST "Control Panel.{21EC2020-3AEA-1069-A2DD-08002B30309D}" goto UNLOCK
if NOT EXIST Private goto MDLOCKER
:CONFIRM
echo Are you sure you want to lock the folder? (Y/N)
set/p "cho=>"
if %cho%==Y goto LOCK
if %cho%==y goto LOCK
if %cho%==n goto END
if %cho%==N goto END
echo Invalid choice.
goto CONFIRM
:LOCK
ren Private "Control Panel.{21EC2020-3AEA-1069-A2DD-08002B30309D}"
attrib +h +s "Control Panel.{21EC2020-3AEA-1069-A2DD-08002B30309D}"
echo Folder locked
goto End
:UNLOCK
echo Enter password to unlock folder
set/p "pass=>"
if NOT %pass%== YOUR_PASSWORD_HERE goto FAIL
attrib -h -s "Control Panel.{21EC2020-3AEA-1069-A2DD-08002B30309D}"
ren "Control Panel.{21EC2020-3AEA-1069-A2DD-08002B30309D}" Private
echo Folder Unlocked successfully
goto End
:FAIL
echo Invalid password
goto end
:MDLOCKER
md Private
echo Private created successfully
goto End
:End

Step 2: Set your password

In the code you just pasted, locate this specific line (about halfway down):

if NOT %pass%== YOUR_PASSWORD_HERE goto FAIL

Delete YOUR_PASSWORD_HERE and replace it with your chosen password. Leave the space before and after the password intact.

Step 3: Save as a .bat file

  1. In Notepad, click File > Save As.
  2. Change "Save as type" to All Files (*.*).
  3. Name the file locker.bat (or anything ending in .bat).
  4. Save it in the directory where you want your secure folder to live.

Step 4: Execute the CMD folder lock

Double-click your new locker.bat file. A new folder named Private will automatically appear. Move the files you want to lock files on PC into this "Private" folder.

Double-click locker.bat again. A black CMD window will ask if you are sure you want to lock the folder. Type Y and press Enter. The "Private" folder will vanish.

Step 5: How to unlock a CMD-locked folder

To access your files again, double-click the locker.bat script. The terminal will prompt you for your password. Type the password you set in Step 2 and press Enter. The folder will reappear.

Technical Deep Dive

How CMD Folder Lock Hides Folders

The 'attrib' command

The code uses attrib +h +s. The +h makes the folder hidden, and +s marks it as a system file. Windows Explorer hides system files by default, which is why the folder disappears from view.

The CLSID Extension

The script temporarily renames your folder to Control Panel.{21EC...}. This specific string is a Windows Class ID (CLSID). Even if someone unhides the folder, clicking it redirects them to the Control Panel instead of opening the folder.

Plain text vulnerability

Because the batch file is a simple text document, anyone can right-click locker.bat, select "Edit", and read your password in plain text. It offers privacy against casual users, but zero security against technical users.

Folder Lock vs File Encryption — Key Differences

Locking a folder with CMD only alters its visibility attributes. The actual files inside remain unencrypted on your hard drive. If a user boots the PC from a Linux USB drive, or simply uses the "Show hidden operating system files" setting, they can bypass the lock completely. True encryption (like AES-256) scrambles the actual 1s and 0s of the files so they cannot be read without the key, regardless of the operating system.

Help & Recovery

Troubleshooting & Recovering from a Forgotten Password

How to unlock folder lock 7 without password? (CMD Script Recovery)

If you used the batch script method outlined above and forgot your password, recovery is extremely simple because the CMD lock is not secure:

  1. Right-click your locker.bat file.
  2. Select Edit (or "Open with Notepad").
  3. Scroll down to the line: if NOT %pass%== YOUR_PASSWORD_HERE goto FAIL
  4. Your forgotten password is listed right there in plain text.

How to access folder in CMD if the batch file is deleted?

If someone accidentally deleted your locker.bat file, your "Private" folder is still there, just hidden and disguised as a Control Panel link. To retrieve it:

  1. Open the Command Prompt (Press Windows Key, type cmd, press Enter).
  2. Navigate to the directory where your folder was located using the cd command (e.g., cd C:\Users\Name\Desktop).
  3. Type the following command exactly to unhide the folder:
    attrib -h -s "Control Panel.{21EC2020-3AEA-1069-A2DD-08002B30309D}"
  4. Rename the folder back to normal:
    ren "Control Panel.{21EC2020-3AEA-1069-A2DD-08002B30309D}" Private
Note on Software Recovery: If you are trying to recover a forgotten password for a third-party application like Folder Lock, you cannot use CMD to bypass it. You must use the software's official serial number recovery tool or master key option provided during purchase. AES encryption cannot be bypassed via terminal.
